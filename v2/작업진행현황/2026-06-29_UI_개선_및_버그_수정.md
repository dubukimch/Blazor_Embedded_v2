# 2026-06-29 UI 개선 및 버그 수정

## 작업 목적

현재 구현된 Blazor UI에서 부족한 부분과 버그를 식별하고 수정하여 사용자 경험을 개선합니다.

## 확인한 문제점

1. **MainLayout.razor**: 페이지 제목이 기술적 이름(`BlazorApp_arduinoSearch_240824_01`)으로 설정되어 있음
2. **MainLayout.razor**: 관련 없는 "About" 링크가 상단 메뉴에 표시됨
3. **LedControl.razor**: Dispose 메서드에 불필요한 공백 라인이 있음
4. **Devices.razor**: MQTT 포트 입력이 텍스트 타입으로 설정되어 있어 범위 검증이 부족함
5. **Devices.razor**: 장비 설정 중 로딩 상태를 시각적으로 표시하지 않음
6. **LedControl.razor**, **DhzChart.razor**, **SensorChart.razor**: UI 레이아웃이 단순하고 시각적 피드백이 부족함
7. **Index.razor**: 초기 페이지의 사용성이 낮고 설명이 부족함
8. **Index.razor**: 반응형 디자인 미흡
9. **DhzChart.razor**, **SensorChart.razor**: 차트 레이블과 메시지가 영문으로만 표시됨
10. **Devices.razor**: 테이블이 모바일 화면에서 반응하지 않음

## 변경 내용

### 1. MainLayout.razor
- 페이지 제목을 "BlazorApp_arduinoSearch_240824_01"에서 "Embedded IoT Dashboard"로 변경
- 상단의 관련 없는 "About" 링크 제거

### 2. LedControl.razor
- Dispose 메서드의 불필요한 공백 라인 제거
- 전체 UI 재구성:
  - 컨테이너 기반 레이아웃 추가
  - 버튼의 크기와 스타일 개선 (btn-lg 사용)
  - 에러/상태 메시지를 Alert 컴포넌트로 변경 (dismiss 버튼 추가)
  - 로딩 상태 표시 (스피너 추가)
  - 한글 라벨 추가 (켜기/끄기)
  - 아이콘 추가 (oi-flash, oi-circle-x)
  - 상태 메시지 한글화

### 3. Devices.razor
- MQTT 포트 입력 타입을 "text"에서 "number"로 변경 (min="1", max="65535" 추가)
- 페이지 제목을 "Devices"에서 "Devices - Embedded IoT"로 개선
- 페이지 헤더 개선 (아이콘 추가)
- MQTT 상태 메시지를 Alert 컴포넌트로 변경 (dismiss 버튼 추가)
- 로딩 상태 UI 개선:
  - 스피너 추가
  - 진행 상황 카드로 감싸기
  - 현재 IP와 발견된 장치 수 표시 개선
- 연결 버튼에 로딩 상태 추가:
  - `configuringDevices` 해시셋으로 장비별 로딩 상태 추적
  - 설정 중일 때 버튼 비활성화 및 스피너 표시
  - try-finally로 로딩 상태 관리
- 테이블 헤더 한글화 (Name→장치명, IP Address→IP 주소, etc.)
- 발견되지 않은 경우 메시지 개선 (Alert 컴포넌트 사용)
- 테이블을 `table-responsive`로 래핑하여 모바일 반응성 개선
- Devices.razor.css 파일 추가:
  - 반응형 미디어 쿼리 (max-width: 768px)
  - 모바일 환경에서 폰트 사이즈와 패딩 조정

### 4. Index.razor
- 전체 UI 재구성:
  - 컨테이너 기반 센터링 레이아웃
  - 카드 기반 디자인으로 개선
  - 기능 목록 (주요 기능 섹션) 추가
  - 요구 사항 섹션 추가
  - 아이콘 추가 (oi-magnifying-glass)
  - 버튼 스타일 개선 (btn-lg)
- CSS 스타일 추가:
  - 카드 스타일 (border, shadow)
  - 버튼 사이즈 커스터마이제이션

### 5. DhzChart.razor
- 전체 UI 재구성:
  - 컨테이너 기반 레이아웃
  - 페이지 제목 한글화 ("DHZ Chart"→"DHZ 센서 데이터")
  - 카드 기반 차트 레이아웃 (온도, 습도 분리)
  - Alert 컴포넌트로 메시지 표시 (dismiss 버튼)
  - 상태 메시지 한글화 (기술 정보 추가: 온도/습도 값)
- CSS 스타일 추가:
  - 카드 스타일
  - 반응형 캔버스 사이징

### 6. SensorChart.razor (Soil Moisture Chart)
- 전체 UI 재구성:
  - 컨테이너 기반 레이아웃
  - 페이지 제목 한글화 ("Soil Moisture Chart"→"토양 습도 센서 데이터")
  - 카드 기반 차트 레이아웃 (온도, 습도, 토양습도 분리)
  - Alert 컴포넌트로 메시지 표시 (dismiss 버튼)
  - 상태 메시지 한글화 (온도/습도/토양습도 값 표시)
- CSS 스타일 추가:
  - 카드 스타일
  - 반응형 캔버스 사이징
