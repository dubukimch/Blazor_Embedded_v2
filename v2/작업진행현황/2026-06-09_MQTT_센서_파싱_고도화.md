# 2026-06-09 MQTT 센서 파싱 고도화

## 작업 목적

현재 코드에서 부족한 기능과 고도화 지점을 점검한 결과, MQTT 쿼리 파라미터 검증과 센서 JSON 파싱 로직이 Razor 화면에 중복되어 있고 테스트가 부족했다. 장비 연동 화면의 실패 내성을 높이기 위해 공통 파서와 단위 테스트를 추가했다.

## 확인한 부족한 점

- LED, DHZ, 토양 수분 화면이 MQTT 주소/포트/토픽 검증을 각각 구현하고 있어 유지보수 비용이 높았다.
- DHZ와 토양 수분 센서 JSON 파싱이 UI 컴포넌트 내부에 있어 실패 케이스를 단위 테스트하기 어려웠다.
- 센서 페이로드 키 이름이 `soil_moisture`, `soilMoisture`, `temp`처럼 장비 펌웨어마다 달라질 수 있는데 기존 구현은 한 가지 형태에 가깝게 묶여 있었다.
- 테스트는 장치 검색 IP 후보 생성 2건만 있어 MQTT 화면 입력과 센서 데이터 파싱 회귀를 잡기 어려웠다.

## 남은 고도화 후보

- 실제 Arduino/MQTT 브로커 환경에서 `configure_mqtt`, LED 발행, 센서 차트 수신을 통합 검증한다.
- 센서 차트 화면에 최근 수신 시각, 마지막 원본 메시지, 파싱 실패 횟수를 표시해 현장 디버깅성을 높인다.
- 장치 종류 판별을 이름 문자열 비교 대신 capability 필드나 device type 필드 기반으로 바꾼다.
