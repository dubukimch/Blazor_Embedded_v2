# 개선 작업 목록

## 관리 원칙

- 상태 값은 `대기`, `진행중`, `완료`, `보류` 중 하나로 기록한다.
- 실제 코드 또는 문서 작업을 수행하면 `작업진행현황/`에 날짜별 작업 로그를 남긴다.
- 작업 완료 조건에는 코드 변경뿐 아니라 빌드/테스트/수동 확인 결과를 포함한다.

## P0: 먼저 안정화할 작업

| ID | 상태 | 작업 | 배경 | 완료 조건 |
| --- | --- | --- | --- | --- |
| P0-01 | 대기 | NuGet restore 후 두 솔루션 빌드 확인 | 현재 `project.assets.json`이 없어 `--no-restore` 빌드가 실패함 | `dotnet restore`, `dotnet build` 결과 기록 |
| P0-02 | 대기 | .NET 6 업그레이드 계획 수립 | 현재 SDK에서 `net6.0` 지원 종료 경고 발생 | 목표 프레임워크 결정, 영향 범위 문서화 |
| P0-03 | 대기 | `/DHZChart` 라우팅 오류 정리 | `Devices.razor`가 존재하지 않는 화면으로 이동함 | 화면 구현 또는 분기 제거 |
| P0-04 | 대기 | MQTT 이벤트 구독/해제 방식 수정 | `LedControl.razor`의 람다 해제가 실제 등록 핸들러와 일치하지 않음 | 명명된 핸들러로 등록/해제, 중복 수신 방지 |

4. README와 진행현황 기록을 계속 갱신한다.
