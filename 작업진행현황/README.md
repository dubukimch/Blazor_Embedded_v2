# 작업진행현황 기록 기준

이 폴더에는 실제 수행한 작업을 날짜별 Markdown 파일로 기록한다.

## 파일명 규칙

`YYYY-MM-DD_작업요약.md`

예시:

- `2026-06-06_프로젝트_분석_및_문서화.md`
- `2026-06-07_MQTT_연결_개선.md`

## 기록 항목

각 작업 로그에는 다음 내용을 남긴다.

1. 작업 목적
2. 확인한 파일/근거
3. 변경한 파일
4. 검증 결과
5. 남은 이슈와 다음 작업

## 운영 규칙

- 개발 또는 개선 작업을 시작하면 이 폴더에 해당 작업 로그를 만들거나 기존 로그를 갱신한다.
- 코드 변경이 없더라도 분석, 설계, 빌드 검증, 오류 조사 결과는 기록한다.
- 실패한 검증도 숨기지 않고 원인과 다음 조치를 함께 남긴다.
